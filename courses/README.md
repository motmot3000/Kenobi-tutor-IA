# Course library

Courses ready to import into Kenobi: download the `.md` file, then in Kenobi › « Ajouter un cours », drop it. The AI
you connected reads it and builds the plan; without AI, the plan comes from the headings.

The official course library, with one-click import, is coming. Until then, this folder is the place to share
courses: **add yours with a pull request** (see [CONTRIBUTING.md](../CONTRIBUTING.md#courses) and
[docs/courses.md](../docs/courses.md)).

| Course | Level | Tools | Language |

## Rules for a library course

- Computer science or programming; one document, Markdown, following the format of [docs/courses.md](../docs/courses.md).
- Your own work, or under a free license that allows sharing and adaptation (say which at the end of the document).
- Lessons of 15 to 30 minutes, one notion each, with observable goals.
- Tested in Kenobi: it imports, and the first lessons work with the tutor.
